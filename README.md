# IoT-research

Šiame projekte pridedami kodo failai kurie buvo naudojami baigiamojo darbo metu

PASTABA: tai nėra konkretus, pilnas ar užbaigtas programinės įrangos kodo projektas, kuris iš savęs veiktų kaip produktas ar paslauga. Šiame projekte talpinami kodo ar apdorotų (csv) rezultatų fragmentai kurie buvo naudojami skirtingais tyrimo etapais bei salygomis. Tiesiog parsisiuntus šiuos kodo failus ir bandant juos "paleisti" negarantuojama, kad bus pasiektas norimas (ar iš vis bet koks) rezultatas, nes tai priklauso nuo daugelio kitų kintamųjų kurie nėra susiję su pačiu kodu.
